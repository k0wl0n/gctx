1. Add "runtime" to the import block. The current imports are:
   "fmt", "os", "os/exec", "strings", "time"
   Add "runtime" so the block becomes:
   "fmt", "os", "os/exec", "runtime", "strings", "time"

2. Replace the shell detection logic inside StartShell() (currently lines 365-368):

   CURRENT CODE:
   ```go
   shell := os.Getenv("SHELL")
   if shell == "" {
       shell = "/bin/sh"
   }
   ```

   REPLACE WITH:
   ```go
   shell := os.Getenv("SHELL")
   if shell == "" {
       if runtime.GOOS == "windows" {
           // Prefer PowerShell Core, fall back to Windows PowerShell, then COMSPEC (cmd.exe)
           if pwsh, err := exec.LookPath("pwsh.exe"); err == nil {
               shell = pwsh
           } else if ps, err := exec.LookPath("powershell.exe"); err == nil {
               shell = ps
           } else if comspec := os.Getenv("COMSPEC"); comspec != "" {
               shell = comspec
           } else {
               shell = "cmd.exe"
           }
       } else {
           shell = "/bin/sh"
       }
   }
   ```

Do not change any other part of StartShell(). The rest of the function (cmd.Env setup, cmd.Run()) is correct.
  </action>

Expected: Compiles with no errors. If "runtime declared and not used" appears, the import was added incorrectly.
  </verify>
  <done>

  </done>
